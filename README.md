# AI SEO Launchpad

**Get Found by AI. Get Recommended by LLMs.**

A complete, self-hosted DIY toolkit for marketers, agencies, freelancers, and business owners who want to dominate AI search — Google AI Overview, ChatGPT recommendations, Perplexity citations, Knowledge Panel, and People Also Search For.

## Tools Included

| Tool | Description |
|------|-------------|
| [Dashboard](index.html) | Central hub linking all tools + Quick Wins guide + AI bot reference |
| [102-Point Checklist](checklist.html) | Full AI SEO checklist with progress tracking (saved locally) |
| [Schema Generator](schema-generator.html) | Generate valid JSON-LD for 12 schema types |
| [Content Optimizer](content-optimizer.html) | AI readiness scoring, snippet optimizer, FAQ generator, templates |
| [llms.txt Builder](llms-txt.html) | Generate your llms.txt file for LLM identity |

## Quick Start

1. Open `index.html` in any browser — no server required
2. Start with the **5 Quick Wins** on the dashboard
3. Work through the **102-Point Checklist** systematically
4. Use the **Schema Generator** to implement structured data
5. Run your key pages through the **Content Optimizer**
6. Deploy your **llms.txt** file to your domain root

## Deployment Options

**Option 1: Local files** — Open `index.html` directly in a browser. Everything works offline.

**Option 2: Static hosting** — Upload to any static host (GitHub Pages, Netlify, Vercel, S3). No backend required.

**Option 3: WordPress** — Upload to your WordPress theme directory and link from the admin menu.

## Technology

- Pure HTML, CSS, and JavaScript — zero dependencies
- No backend, no database, no API keys
- Progress tracking via localStorage (private, stays on device)
- Works on all modern browsers
- Mobile responsive
